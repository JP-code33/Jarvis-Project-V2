# Jarvis-Project-V2
Hello Everyone! This is my version 2 of my Jarvis and it has been made that now you can just talk to it!

I had a version 1 where I had hard coded all the commands and you had to type but in this version you can simply say "Jarvis", wait for it to activate and say the command to it. It uses a Google Gemini API key to answer questions so that I don't have to hard coded anything. 

I have made it in an executable file which is found in my Release section of this project. You just simply have to download it and double click on the downloaded file and then Jarvis will start running on your device. If the device doesn't have any type of microphone input then the program will terminate by itself. 

First you have to wait and then when you see listening on the screen by Jarvis then you say "Jarvis" and wait for it to activate (it is like a wake up call). Then once it is activated it will say "Yes Sir" then you can just tell your command to it. It does take a while to answer questions which uses Google ai. 

Thank you for testing my Jarvis!
